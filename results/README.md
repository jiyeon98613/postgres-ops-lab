# 검증 결과

실제 운영 백업을 사용한 실행 결과는 아직 없습니다. 실행을 완료한 뒤 다음 정보만 검토하여 추가합니다.

- 백업 파일 크기·확인 날짜, PostgreSQL 버전
- 복원한 테이블 수·전체 행 수, 백업과의 일치 여부, 시퀀스 확인 결과
- 테이블 삭제 확인과 새 DB 복구 결과
- 인덱스별 조건, 반복 횟수, 실행 시간·버퍼 통계, 상수를 제거한 실행계획
- 역할별 허용·거부와 SQLSTATE

백업 파일, DB 접속 정보, 행 값, 개별 행 해시, SQL 매개변수, 원본 실행계획과 로그는 공개하지 않습니다. 코드 검증용 데이터의 수치를 운영 데이터의 결과로 옮기지 않습니다.
